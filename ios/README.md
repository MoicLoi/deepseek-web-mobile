# DS-LA-reviewer · iOS 单页版

`deepseek-studio.html` 是面向 iPhone / iPad Safari 的单文件版，教材数据已内联，零依赖、无需构建。

## 功能

- 强制接入 DeepSeek API，没有游客模式或试用额度
- 《实验动物学导论》全文 + 书末例题本地检索（约 618 个片段）
- 查阅 / 出题 / 片段练习 / 模拟练习 四种模式
- 练习模式第一问先让用户选题型，默认参考书末例题：6 单选 + 4 判断（100 分）
- 所有模式默认开启联网搜索交叉验证；教材优先，网络补充
- SSE 流式回复、深度思考、来源引用
- 单轮 / 整段对话导出 `.md`，通过 iOS 分享面板发送到其他 App
- 多会话、本地保存、浅色 / 深色 / 跟随系统
- 适配 iOS 安全区、软键盘与 `visualViewport`

## 使用

把 `deepseek-studio.html` 放到任意 **HTTPS** 静态空间，用 Safari 打开。点击「分享 → 添加到主屏幕」即可。

本地预览：

```bash
cd ios
python -m http.server 8092
```

打开 `http://127.0.0.1:8092/deepseek-studio.html`。

> 直接双击 `file://` 打开时，Safari 可能限制 `localStorage` 与跨域请求，建议使用 HTTPS 托管。

## 教材数据

单文件内联了以下内容：

- 7 章 46 节正文、附录一至七
- 书末附录七的 6 道单选题 + 4 道判断题
- 约 618 个带章节/节标注的检索片段

提问时按中文 2–4 字组合做本地关键词召回，把命中片段注入系统提示词；练习/出题模式额外注入目录与书末例题。

## 限制

- 教材由照片转写、校对而来，仍可能有 OCR/排版残留错误；以纸质教材与现行标准为准。
- 本地检索是关键词召回，不是语义向量检索；目录外细节可能召回不足。
- 单页版聚焦文本复习，不含文件、语音、朗读、Mermaid / KaTeX。
